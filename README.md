## Part A - Student Management

This program manages student data using an `ArrayList`.

It can:
- Add students
- Display the student list
- Calculate the average score
- Sort students by score
- Search for a student by name

The `Student` class stores the student's name and score.

## Part B - Book System

This program uses a `Book` class to store book information.

It includes:
- Book title
- Author
- Borrowing status
- Borrowing and returning methods

The program also has a rule that prevents a book from being borrowed if it is already borrowed.
